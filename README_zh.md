## 为什么写这本书？

AI 正在变得无所不能：写作、编程、设计、分析……

一个自然的问题是：**人类还剩什么？**

这本书的答案是：不是"什么都没了"——而是"更深层的某些东西"。

与其在速度和数量上与 AI 竞争，不如把 AI 当作**陪练、镜子和杠杆**，去构建机器从根本上无法复制的能力：判断力、审美、情感共鸣、跨领域思维。

这不是一本讲 AI 工具的书。这是一本关于**你**的书。

---

## 核心主张

> AI 是你从未有过的最佳训练伙伴。用它来锻造它无法取代的东西。

全书围绕一个简单的循环展开：

```
AI 生成 → 你判断 → 你打磨 → 你内化 → 你升级
```

## 双语策略

本书**先以英文写作**，再翻译为中文。

- 英文版 → 源文件，面向全球读者
- 中文版 → 本土化案例、文化语境、表达习惯

仓库结构：

```
/chapters
  /en    ← 英文章节（source of truth）
  /zh    ← 中文翻译
/paid
  /en    ← 付费内容（英文）
  /zh    ← 付费内容（中文）
```

### 为什么做双语？

用两种语言写作，本身就在训练**跨语言思维**——这正是本书所倡导的元能力之一。你会发现，有些想法翻译得很顺畅，有些则会在语言转换中暴露出隐藏的假设。这些"卡住"的瞬间，往往藏着真正的洞见。
